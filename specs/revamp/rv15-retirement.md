# RV-15 retirement audit (first slice)

The production entry is `src/main.tsx` → `src/App.tsx` → `features/session/openStudioRepository`, which opens only `persistence/studio` (`system-studio-local-v1`). The browser worker is created in `features/workspace/Workspace.tsx` from `features/runs/runner.worker.ts`; its protocol uses the current scenario runner. The v9 reader/writer lives in `persistence/studio`. The old editor, project persistence, and simulation worker/engine files are absent. `src/legacy-boundaries.test.ts` rejects new production imports of those paths.

The former revision helper is retained: although it has no direct runtime caller, `domain/model.ts` imports its `ArchitectureRevision` type. No source files or tests were retired in this slice. The old graph/results/notes types remain connected to `domain/execution.ts` and `domain/workload.ts`, which the open simulation kernel still uses; they need a separate type decoupling before removal. The open kernel and its golden files were not changed. GSAP and its React wrapper had no source imports and were removed from the dependency manifest and lockfile.

Bundle baseline (`npm run build` at `116f078`): main JS 1,599.67 kB (430.34 kB gzip), worker JS 234.94 kB, CSS 153.47 kB (28.90 kB gzip). After this slice on that base: identical emitted assets (0.00 kB delta), as expected for removing packages with no source imports.

After rebasing onto the newer UI commit `847ada6`, the build emits main JS 1,626.71 kB (438.02 kB gzip), worker JS 234.94 kB, and CSS 153.73 kB (28.93 kB gzip). Verification on the rebased commit: 1,391 unit tests, TypeScript/Vite build, and production Chromium journeys (69 passed, 4 skipped) pass.

## Second slice: legacy graph-model island

`ComponentKind` now lives in `domain/execution.ts`, and `domain/workload.ts` keeps only `TrafficProfile`, `rateAt` and `nextArrivalTime` over a structural `ArrivalSettings` (traffic, duration, profile) — the shape the kernel already passes. The open kernel, `behaviors.ts`, `behaviorDefaults.ts`, the catalog and the studio model therefore import nothing from the old graph schema. With that edge cut, the old graph-model island had no importers and was deleted: `domain/{model,results,openResults,metrics,notes,subsystems,revisions}.ts`, plus the workload comparison/label/validation helpers that only its results code used. The one retired test file, `domain/notes.test.ts` (4 cases), validated the old `Project.notes` format; studio notes are validated by the studio model validator. The kernel and its golden files are unchanged; the characterization tests pass. `src/legacy-boundaries.test.ts` now also rejects production imports of the deleted domain modules, resolving relative specifiers so `domain/studio/model` is not confused with `domain/model`. Emitted assets are identical to the first slice (the island was already tree-shaken).

## Third slice: stylesheet audit

`src/styles.css` is the only app stylesheet. Of its 201 class selectors, only `component-node` and `selected` (NodeCard) are applied by current source; string tokens such as `field`, `note` or `failed` matched only data values, comments and messages, and no class name is built from a template. The other live classes are added at runtime by `@xyflow/react` (`react-flow__*`, plus its state modifiers). Every selector naming any other class was removed (570 selectors), along with the three keyframes only those rules used (`export-spin`, `legacy-pulse`, `traffic-flow`), orphaned comments, and six legacy custom properties nothing reads any more (`--paper`, `--canvas`, `--muted`, `--teal-soft`, `--amber`, `--amber-soft`). The file goes from 2,833 to 517 lines; built CSS goes from 153.73 kB (28.93 kB gzip) to 114.93 kB (21.05 kB gzip).

Kept on purpose: the token blocks (`@theme`, `:root`), element and base-layer rules (`button:not([data-slot])`, `input`, `select`, headings, scrollbars, reduced motion), and the unscoped `react-flow__*` overrides, because all of them still style the new app. Among them, the legacy `--line`/`--ink`/`--teal` values in base button/input rules and the selected-edge stroke `#c48212` predate the Evergreen tokens; restyling them would be a visible change, so it belongs to a design package, not to retirement. The `.dark` block in the token section is never applied (no dark class or ReactFlow `colorMode` is set); it is left for the token owner (RV-01).

Visual verification compared a build with the old stylesheet against the pruned one, driving the same journeys on both: entry, S05 workspace, node inspector, Library panel, History ladder, project menu, and a completed S04 run with Details open, each at 1512×982 and 390×844. For all 14 states, every element's computed style (order-insensitive, excluding the six removed properties) and bounding box matched, and the full-page screenshots were byte-identical.

RV-15 retirement gates are complete. The new-project, template, run, import rejection, and old-database untouched journeys still need production browser verification after any broader retirement.
