# AI chat and activity UX review

Implementation is on PR #13. This audit supersedes the earlier shared AI/Inspector dock description for chat presentation. agy qualification remains explicitly blocked.

## Implemented behavior

- assistant-ui's external-store runtime presents existing controller messages and Markdown; Canvas One retains local transport, durable history and board-write authority. No Assistant Cloud, API credential management or automatic inference retries were added.
- The independent floating AI panel retains inline connection setup and hides its composer until connected. Provider selection and destructive Disconnect remain beside Send; typography inherits the app's foundation.
- Send presents the represented attempt's activity face and exact Stop action. Independent questions retain their own cancellation target while an editing task continues. One concise activity line accompanies an expandable Details log.
- Board reviews retain validated Accept/Reject and conflict handling. Review undo prepares a human-reviewed reversal rather than silently applying it.
- Canvas presence requires an actual visible target. Appearance waits 200ms from presentation observation, independent of controller timestamp origins. A displayed successful operation receives up to 700ms of truthful completed feedback; failures, required decisions, explicit Stop, departure and scope changes clear presence immediately.

## Review findings and limits

The external review found a real cursor-clock mismatch: controller timestamps defaulted to `performance.now()` while presentation subtracted them from `Date.now()`. Presentation now measures the delay from first observation, with a mismatched-clock regression. Completed tasks also advance their generation; successful receipt matching now permits only the exact finished attempt through that one terminal transition. Controller success retention is being coordinated separately so ordinary completion does not cut short an already displayed success badge.

Other reviewer findings concern Markdown URL normalization and clipboard availability, actionable notice classification, submission/review concurrency, streaming attribution and trusted Undo identity. Final correction and verification status belongs in the lead's closing entry; this document does not claim a final independent approval.

The initial real Claude rename probe emitted four invalid change envelopes before a valid fifth submission. The tool schema had described change items only as objects. Both submission tools now expose the exact insert/replace/remove envelope, singular record kinds and complete-record replacement semantics. The corrected natural-language rename passed in **24.9 seconds**: real signed-in Claude CLI, scoped MCP, board inspection, one valid first-try proposal, explicit human acceptance, correct node rename, one durable task journal entry and zero browser errors. Final evidence is ignored under `artifacts/ux-review/real-provider/`; this run replaced the earlier probe output directory, so its JSON is evidence of the corrected run only.

Configured Gemini critic passed. Two configured Opus review rounds found actionable clock, URL/clipboard, submission concurrency, stream attribution and Undo-origin/replacement issues; these were repaired and lead-reviewed with targeted regressions. The second round is not claimed as an independent pass. Its request to retain presence while awaiting review conflicts with the approved immediate-clear-on-required-decision behavior and was intentionally not adopted. Existing loopback validation and interrupted-accept recovery were verified rather than duplicated. Automatic cancellation acknowledgments remain a safety retry; they never restart inference or restore board-write permission.
