# Diagram SVG/PNG export

Parent owns architecture and pure SVG renderer/tests in src/export/diagramSvg.ts and diagramSvg.test.ts. Delegate owns browser download adapter src/export/downloadDiagram.ts, DiagramExport UI, App integration, narrow CSS additions, tests/export.spec.ts and documentation after implementation.

## Contract

Parent provides `renderDiagramSvg(project: Project): { svg: string; width: number; height: number }` and `pngDimensions(width: number, height: number): { width: number; height: number }` from src/export/diagramSvg.ts. Renderer throws human-readable Error for non-diagram/empty/invalid or excessive coordinate extents. No browser globals, DOM capture, foreignObject, remote assets or new dependencies. Full graph independent of viewport/selection. Preserve current collapse state; project visible group boundaries and boundary connections, suppress internal edges only when collapsed. Names, type labels, notes (bounded visible lines, full metadata in SVG title), directed and classified paths. Export is a clean vector rendition, not pixel-identical screenshot. Preserve actual node positions and render compact cards, no editor decorations. Text/XML must be safely escaped. SVG uses system sans-serif; PNG has white background. Parent tests injection handling, negative coordinates, bounds, collapsed mapping, self/backward paths, immutability and sizing.

## Delegate implementation

Implement `downloadDiagram(project, format: 'svg' | 'png'): Promise<void>` (or equally clear named export) using renderDiagramSvg and pngDimensions. SVG: Blob MIME image/svg+xml and temporary download anchor. PNG: SVG Blob object URL -> Image decode/load -> correctly sized canvas draw -> asynchronous canvas.toBlob image/png -> anchor download. Handle image load/toBlob/context failures and revoke all object URLs in finally, including rejection. Delay download URL revoke safely until browser has consumed anchor. No remote requests, no foreignObject, no local filesystem writes in product. Sanitize project name for a bounded safe filename ending .svg/.png; fallback architecture-diagram. Repeated exports must not leak canvases/URLs or mutate graph/selection/history/viewport. PNG dimensions capped by parent helper at 8192px side and 16 million pixels, preferred 2x when within bounds.

Add compact diagram-only export controls via focused DiagramExport component with SVG and PNG buttons, >=44px touch targets. Disable when graph empty; a pending state prevents overlapping requests. Show progress, accessible failure message and success download feedback. Error path must permit retry. Explain 'Entire diagram · current subsystem view' and PNG scale cap where useful. Don't show simulation export controls or suggest JSON replacement. Preserve existing JSON backup.

Follow relevant frontend skill instructions, minimal changes to established layout. Use existing App/library or project panel layout; avoid floating another obstruction over canvas. Avoid editing parent's files. Unit tests for adapter cleanup/error paths if practical; browser tests must download both formats, parse SVG XML and decode PNG, verify off-screen components included, collapsed groups/metadata are represented, and export does not mutate project or viewport. Test desktop and mobile access. Assertions should inspect downloaded content, not merely success toast. Save clean UI evidence and one raster export artifact for inspection. Use real pointer interaction.
