# Lessons

Rules learned from past failures, corrections and wasted effort. Loaded every session on every platform. Follow them; cite the rule when it changes your approach.

Maintenance (see `AGENTS.md` §6 and `/retro`):

- A rule lands here only if it would change what a future agent does. No history, no current state.
- Format: imperative rule, then `Why:` with the source `ACTION_LOG.md` date.
- Contradicted rule → replace it. Stale rule (tool fixed, invariant changed) → delete it.
- Hard cap: 50 rules. Over the cap → merge or drop the weakest.

## Environment and tools

- **Treat headless `agy` exit 0 with empty output as a failure.** In plan mode it auto-denies `read_file`/`command` and exits silently. Why: 2026-09-23 EXEC-PREFLIGHT.
- **Don't retry `agy` in a restricted sandbox.** It needs localhost binding and writes under `~/.gemini/antigravity-cli/`; request elevated permissions once or record the task as blocked. Why: 2026-09-10, three failed retries.
- **Typecheck with `npx tsc -b`; never pass `--noEmit false`.** The solution-style root makes `tsc --noEmit -p .` skip `src/`; overriding `noEmit` writes a `.js` beside every source file. For unused-symbol sweeps use a throwaway tsconfig extending the root with `noUnusedLocals`. Why: 2026-10-02 quality sweep and checkpoint removal.
- **Don't rely on `timeout` or `agy --print-timeout` on macOS.** Use `perl -e 'alarm N; exec @ARGV' <cmd>`. Why: 2026-09-23, 25s timeout ran 79s.
- **`.claude/skills` and `.codex/skills` are symlinks into `.agents/skills`.** Check with `ls -l`; `diff -rq` follows the links and misleads. Why: 2026-09-16 wrong duplication finding.
- **Production e2e needs localhost binding, and Codex's sandbox can't run Chromium.** Ask for elevation up front or keep browser checks with the lead; if denied, report the browser check as blocked. Why: 2026-09-10, 2026-09-12, 2026-09-27 RV-12f/RV-12g.
- **Unit timeouts on a busy machine aren't failures until rerun.** Check `uptime`; rerun the timed-out files alone and record both results. Why: 2026-09-24 RV-08a, 2026-09-26 RV-11a, 2026-09-27 RV-12e (load average 16–25, different files each run).

## Verification

- **Before calling UI, CSS or app-shell work done, run `npm run build`, then the full production browser suite on an isolated port.** The isolated config serves the existing `dist` via `vite preview`, so skipping the build tests the old app (2026-09-30 RV-24). `playwright.config.ts` reuses any server on 5174 (possibly a stale build); use a throwaway config with its own port, `reuseExistingServer: false`, 2 workers and no retries. Fixing the named selectors isn't enough; CSS alone broke the export journey. Why: 2026-09-14, 2026-09-15, 2026-09-27 onward.
- **Put the throwaway Playwright config inside the repo (untracked, delete after) and set `TEST_PRODUCTION=1`.** A config in the scratchpad can't resolve `@playwright/test`; without the variable the dev-only specimen specs run against `vite preview` and fail. Why: 2026-10-04 cycles stage 1.
- **One passing run doesn't prove a flaky test is fixed.** Say so in the log. Why: 2026-09-10.
- **Keep every build chunk under Vite's 500 kB warning; a new size warning is a regression.** Check with `npm run build`. Why: 2026-09-29 bundle split removed the long-standing warning.
- **Custom colour utilities (`text-ink`, `bg-canvas`, `border-hairline`) only work if `--color-<name>` is defined in `src/styles.css` `@theme inline`.** In Tailwind CSS v4, `--color-*` variables declared only in `:root` do NOT generate utilities (`border-*`, `bg-*`, `text-*`). After using a new token class, grep `dist/assets/*.css` for it. Why: 2026-09-29 RV-17 and 2026-10-01 component discrepancy audit.
- **Unit tests must be `src/**/*.test.ts`; `.tsx` test files never run.** Render components with `React.createElement` + `renderToStaticMarkup`. Why: 2026-09-28 RV-11a review caught a `.test.tsx` file.
- **An axe-clean run isn't an accessibility pass; also probe keyboard focus and 320 px reflow.** Open each overlay with Enter, close it with Escape and read `document.activeElement`; check `scrollWidth` and clipped controls at 320×640. Verify capture-dependent gestures with native browser touch input, and measure coordinates after touch emulation changes coarse-pointer CSS. axe can't flag an overlay that lacks a dialog role. Why: 2026-09-29 accessibility pass (axe found 2 of 6 defects); 2026-10-05 cycle pinch checks.
- **E2E screenshots and files go to `test.info().outputPath(...)`, never repo or absolute paths.** Why: 2026-09-29 RV-13 and debt cleanup (scratchpad paths from an old session, `artifacts/rv-12e/`).
- **In test specimen and review pages, ensure no non-target element captures initial keyboard Tab focus, and preserve DOM order.** When tests assert keyboard focus on the first button (`page.keyboard.press("Tab"); await expect(firstButton).toBeFocused()`), focusable elements like `<details><summary>` before the target intercept focus, and matrix tables placed before the primary variant shift `getByRole('button').first()`. Why: 2026-09-30 design system specimen alignment.
- **Keep Storybook/browser test plugins decoupled from core Vite/Vitest configs.** The `@storybook/addon-vitest` or `storybookTest` plugin injects browser/Playwright runners into Vitest; keeping Storybook testing in a dedicated `vitest.storybook.config.ts` prevents standard `npm test` from being intercepted and failing with browser timeouts. Why: 2026-10-01 Storybook setup.
- **E2E that expects the entry screen must `page.goto('/')`, not `page.reload()`.** With URL routes, reload inside a project keeps the project open. Why: 2026-10-02 URL routes.

## Delegation and review

- **Check delegate output and reviewer claims against source before applying them.** Delegates got FIFO/reservation accounting, cancellation order and random draws wrong; reviewers cited wrong callers and stale decisions. Why: 2026-09-13, 2026-09-22.
- **For UI lanes, probe the changed interaction in a browser before trusting a review.** A Sonnet review passed a multi-select change that cleared the selection; a 20-line Playwright probe caught it. Why: 2026-09-30 RV-20.
- **Headless agy won't respect command allow-lists or prompt-level shell limits; pick skip-permissions (with user approval), another executor, or a source-embedded patch-only prompt before dispatch.** Patch-only keeps implementation delegated without granting blanket shell access; the lead must apply, test and independently review it. Why: 2026-09-30 RV-20 and composite-board revalidation.
- **Self-reviewed corrections don't close a review.** Closure needs an independent reviewer (fresh session or subagent). Why: 2026-09-23 S05.
- **Start every executor prompt with "you are an executor: don't use /delegate or spawn agents".** AGENTS.md §2 tells every agent to delegate, and Codex started a nested `/delegate` run instead of implementing. Why: 2026-09-30 RV-19 lane.
- **Don't run `state.py dispatch` while any lane of the round is live.** It treats a `.pid` as orphaned and kills that lane. Re-dispatch only after the round has finished. Why: 2026-09-30.
- **Smoke-test an executor with a no-edit prompt before dispatching real lanes.** Why: 2026-09-23 preflight caught a blocked executor cheaply.
- **Reject invented defaults in delegate code.** Grep delegate diffs for fallbacks such as `?? 'unknown'`, `|| 'main'`, success inferred from a missing outcome, zero-filled counts, placeholder labels and `as unknown as` casts; the contract needs an explicit value or a typed rejection. Why: review rounds on 2026-09-24 (RV-14d/e/f, RV-08c/e, RV-16b), 2026-09-26 (RV-11a), 2026-09-28 (RV-05c).
- **Run each executor lane in its own git worktree and commit partial work.** Quota and rate-limit hits interrupted Gemini, Sonnet and Codex lanes about 10 times; intact worktrees let another executor resume. Why: 2026-09-24 → 2026-09-29.

## Workflow

- **For existing-app design proposals, copy the current theme tokens and appearance rather than approximating colours or inventing a dark palette.** Vary layouts independently of the theme. Why: 2026-10-04 playback mockup colour correction.

- **On long tasks, record status in `ACTION_LOG.md`/`HANDOFF.md` as you go, not only at the end.** A session that runs out of tokens leaves work unrecorded. Why: 2026-09-23 Codex round.
- **Before deleting a branch, prove it is merged into the intended target with `git merge-base --is-ancestor <branch> <target>` (or `git cherry` for rebased work).** `git branch -d` only checks the current checkout, and this repo has no remote, so a deleted unmerged branch is gone. Why: 2026-09-29 cleanup.
- **In zsh, unquoted `$VAR` holding several paths is one word; loop over them explicitly.** A multi-file `cp`/`checkout` silently did nothing. Why: 2026-09-29 RV-17 before/after build.

## Code

- **Keep playback state valid across checkpoint and eviction boundaries.** Preserve unfinished occupancy, reset a cached frame when a jump moves the retained boundary past it, and checkpoint only complete observable instants. Test initial and same-millisecond deltas across worker batches. Why: 2026-10-04 stages 3/4 found disappearing queues, stale active counts and partial checkpoints masking later measurements.

- **Give every retried or redelivered kernel operation its own path (`~n`, `#n`).** Seeded draws are keyed by unit, path and attempt, so a reused path replays the same failure on every retry. Why: 2026-09-30 RV-25 (redelivery failed the same messages forever).

- **Build test and audit graphs through the app's own planners (`placeEntry`, `planConnection`), not hand-built records or `behaviorDefaults.ts`.** `behaviorDefaults` is test-only and differs from the catalog, and hand-built fixtures hide connect rules the canvas enforces. Why: 2026-09-30 realism phase 3 (phase 1 probed defaults the app never loads; G1 and B1–B8 surfaced only through the planners).

- **Don't split with `React.lazy`/Suspense on user-facing paths; use `src/lib/lazyComponent.tsx`, and time the affected interaction against a baseline build.** React 19 throttles Suspense reveals ~300 ms even for cached chunks. Why: 2026-09-29 bundle split made project open 830 ms.
- **Put element-level defaults in `src/styles.css` inside `@layer base`.** An unlayered `p`/`h3`/`select`/`button` rule beats every Tailwind utility on that element, so the classes silently do nothing. Why: 2026-09-29 board comparison (error text grey, all `p`/`h3` forced to 12 px, menu rows boxed).
- **Before deleting superseded code, port its tests to the replacement.** The ported budget tests exposed a status bug in the production runner. Why: 2026-09-29 logical runner retirement.
- **Assert `checkReadiness(...).ready` before `runScenario` in tests.** `runScenario` doesn't run readiness, so a scenario the app's Run would refuse can still pass. Why: 2026-09-30 RV-26 (S06 first draft had an unmodeled element in scope).
- **Run studio graphs under a workload as well as with finite inputs.** Without enabled workloads the kernel skips structural validation (`requireRunnable: false`), so S05's broker call route passed while the same graph under traffic threw. Why: 2026-09-30 RV-22.
- **In `ScenarioRunner` budget tests, account for the terminating attempt and the next step-boundary check.** `processedEvents` can include the attempt that crosses `maxEvents`, while an exact event count still needs headroom for the runner to observe quiescence. Why: 2026-09-30 RV-19 near-limit test needed two corrections.
- **Do not render Radix `DropdownMenu.Item` outside an active `DropdownMenu.Root`.** Radix throws at runtime if items are mounted statically or outside a menu context (`MenuItem must be used within Menu`); for static previews or declarative menu panels, render styled DOM elements with `role="menuitem"`. Why: 2026-09-30 dropdown component standardization.
- **When expanding a compact toolbar into an in-place multi-row container, handle nested drag-and-drop targets gracefully.** Dragging to the container from an outer or child element targets the container's geometric center (often landing in a middle shelf/row); ensure drop handlers differentiate item sources (e.g. moving dock item to shelf to hide vs dropping an available item anywhere on the dock to add) without dropping or swallowing events. Why: 2026-10-01 16C-4 dock expansion implementation.
- **Foundation-first UI edits: check `src/components/ui/` and tokens before styling feature code.** Update shared primitives for surfaces and states, and verify with Storybook. Keep runtime decorations outside measured node layout so links stay fixed. Budget canvas space against the entire Results region (including timeline/controls); cap and scroll it on short viewports. In browser playback tests, wait for the sought animation frame before reading decorations; arrival and return departure can coexist. Why: 2026-10-01 Dialog/QuickOptions audits; 2026-10-04 occupancy changed port geometry, the timeline squeezed a short viewport's canvas to zero, and flash assertions read the previous frame.
- **Do not combine `aria-pressed` with `role="tab"` on segmented or toggle elements.** WAI-ARIA and Axe treat `aria-pressed` on a `tab` as a critical `aria-allowed-attr` violation (tabs allow only `aria-selected`). For segmented tool switchers or toggle groups, default to `role="group"` with native buttons using `aria-pressed`, and reserve `role="tablist"`/`role="tab"` strictly for tabbed view switchers with `aria-selected`. Why: 2026-10-01 Canvas dock toolbar segmented toggle.
- **In panel actions and layout calculations, evaluate `effectiveLayout(state)` instead of stored preferences (`panel.collapsed === false`).** Responsive constraints can auto-collapse panels when viewport bounds or dock occupancy cannot fit them. In user actions (`OPEN`, `EXPAND`), evaluate effective layout visibility before early-returning, and dynamically clamp effective side widths to available space (`computeEffectiveSideWidth`) rather than letting oversized preferred widths push candidate panels permanently into the collapsed rail. Why: 2026-10-01 side panels at 1225px.
- **Do not bind ReactFlow's internal `onSelectionChange` directly to top-level app selection when an application enforces guarded navigation invariants (`Workspace.runGuarded`).** ReactFlow's internal store fires `onSelectionChange` on every single click/drag, which will unintentionally wipe out Shift+click multi-selections and fight with the navigation guard. Instead, capture marquee box selection gestures specifically between `onSelectionStart` and `onSelectionEnd`, translating the captured placement IDs to element IDs on gesture release. Why: 2026-10-01 marquee selection vs Shift+click guard conflict.
- **Give every cmdk `Command` list an explicit word-prefix `filter`.** cmdk's default scoring is a subsequence match, so a short query like "note" matched nearly every row. Why: 2026-10-02 Quick options search.
- **When adding a panel, grep for literal panel-id lists and `Record<PanelId, …>` first.** The panel reducer held ten such sites; missing one leaves the panel half-wired. Why: 2026-10-02 Library "Ours" tab / hosted inspector.
- **Keep the pointer target of a hover-expanding control a persistent element.** If hover swaps the element under the cursor (button replaced by a card), Chrome sends no `click` because the mousedown node left the DOM; put `onClick` and pointer events on the stable root and make the swapped child `pointer-events-none`. Why: 2026-10-03 comment bubbles (taps and fast clicks never pinned the note).
- **Put anything another project reads at project level (`ProjectRecord`), not in a document.** Editing Main auto-creates a draft branch, so no single snapshot is "the project's current state". Why: 2026-10-03 exposed endpoints (the first design read exposures from Main and found nothing).
- **In e2e, drop new canvas nodes in empty space before dragging handles.** Handles under another node take the pointer and xyflow swallows the drag silently. Why: 2026-10-03 linked-project connect test.
- **Use `minmax(0, 1fr)` for responsive grid tracks containing fixed-width previews, and constrain their children.** A `1fr` track retains the child's intrinsic minimum even when the child has `max-width: 100%`, causing page overflow. Why: 2026-10-05 unified simulation design's 320 px browser check.
- **Put zoom and pan on the existing main timeline and share its time window with detail views.** Do not introduce a second overview unless requested. Keep hover summaries in popovers and click expansion attached to the selected row. Why: 2026-10-05 user correction to the simulation-panel proposal.
- **Keep cycle recordings visible at every zoom level.** Use expandable groups with summaries when crowded; do not replace recordings with a zoom-required placeholder. Keep range selection and Loop in the playback transport group. Why: 2026-10-05 browser comments on the simulation-panel proposal.
# Timeline range interaction

- For a state-by-state traffic redesign, name each state's owner and show simultaneous conditions explicitly before multiplying visual variants. Caller awaiting-response counts cover outstanding synchronous calls across transport, downstream queue and processing; they are not receiver occupancy or connection in-flight counts. Treat concurrency/playback as context, direction dots as bounded motion cues, and request outcomes separately from node health. Why: 2026-10-05 user rejected the four-system gallery and later found receiver incoming labels and count-driven dots confusing.

- Distinguish simulation Results inspection from the right-side node/connection configuration inspector. Resolve ambiguous inspector references before attaching simulation events to authoring selection or draft guards. Why: 2026-10-05 integration-plan correction.
- For range statistics, define cycle membership and interval versus lifetime scope explicitly. Never obtain interval means, percentiles, maxima or gauges by subtracting cumulative summaries. Why: 2026-10-05 selected-range inspection plan.
- Range overlays must pass pointer input through except at their handles, so dragging within an existing selection can create a replacement range. Keep persistent detail toggles outside scrolling content.
- Group cycles only in locally crowded intervals; preserve individual rows in sparse intervals even when the overall recording is large.
- Capture causal cycle/unit/parent identity when recording facts, before trace-only bookkeeping consumes them. Preserve completion/reopening periods when querying historical intervals, and label aggregate cycle outcomes as all-work outcomes because asynchronous descendants can fail after a successful response. Apply these distinctions to design fixtures too: declare capacity provenance, separate unit counts from cycle counts, and render terminal events separately from current transport. Why: 2026-10-05 simulation inspection integration and traffic concept review.
- Responsive inspection layouts must switch grid tracks using available container width as well as viewport breakpoints. When replacing a control, search shared test fixtures, feature suites and audit journeys for its old selector/API; tests setting playback speed before a recording must defer until transport exists. Why: 2026-10-05 narrow-panel review and pace-suite migration.
- In playback browser tests, await each rendered speed step before clicking again; React handlers can retain the previous speed until the next render. Disable shared automatic acceleration in suites controlling speed explicitly. Why: 2026-10-05 compact timeline tests exposed duplicate-step and competing-handler races.
- Verify installed resizable-panel size units before setting constraints: this version treats numeric min/max sizes as pixels, while layout values are percentages. Use explicit percentage strings for proportional bounds. In production browser tests, locate library separators by accessible role/name because the library removes test IDs. Why: 2026-10-05 timeline resizing exposed clipped playback controls and a missing separator test locator.
- Size compact simulation panels from measured visible controls, not a fixed workspace percentage. Return hidden inspection space to the canvas, fill expanded inspection with a min-height-zero flex viewport, and preserve explicit timeline collapse. Keep navigation available in narrow detail subviews when its usual list pane is hidden. Why: 2026-10-05 whitespace and left-pane-header corrections.
- Read SVG DOMPoint coordinates explicitly; object spread omits inherited x/y getters. Geometry tests must include browser-shaped points and real SVG rendering, rather than only plain-object stubs. Why: 2026-10-05 Storybook traffic review exposed packets positioned at the canvas origin despite passing plain-object tests.
- Verify actual canvas node bounds after responsive resizing, not just page overflow. In fixed controlled ReactFlow fixtures without onNodesChange, use fitBounds after viewport measurement; fitView queues a node update that may never be applied, and useNodesInitialized can stay false because user-node dimensions are not updated. Why: 2026-10-05 state-lab screenshot exposed clipped nodes despite no page overflow.
- Interactive controls inside read-only ReactFlow nodes need scoped pointerEvents:auto plus nodrag/nopan; verify a real pointer click rather than forcing it through the canvas pane. Why: 2026-10-05 multi-dependency inspection button was rendered but the pane intercepted clicks.
- Current waiting summaries list only outstanding blocking services and pending counts, not downstream processing/queue state; returned branches remain in inspection history. Idle nodes have no activity footer. Active footers stay compact and expand on hover/focus, with a touch alternative. Render independent positive processing, queue and dependency-wait populations together rather than choosing one exclusive node state. Why: 2026-10-05 waiting-footer and simultaneous-activity corrections.
- Traffic state lab connection motion uses theme teal/slate gradients and three bounded dots independent of population, with thin rounded bands and separated opposing streams. User preferred this earlier language over chevrons; refine it rather than replacing it wholesale. Why: 2026-10-06 direction-design correction.
- Model repeated response arrivals over time: show bounded event increments and remaining current waits, with delivered totals separate. Do not render a high-traffic population as one simultaneous delivery event. Why: 2026-10-06 repeated-delivery correction.
- When retiring a Storybook design, audit every registered section and generated docs, including standalone foundation specimens; removing the feature gallery alone can leave the rejected design visible. Preserve unrelated stories and runtime components. Why: 2026-10-06 traffic cleanup missed TrafficFlash and Node occupancy.
- For live or stress variants of an approved design, reuse its node and connection renderers; change data and timing rather than recreating visual markup. Verify visual details and expanded bounds, not just counts or overflow. Why: 2026-10-06 live traffic fixtures used generic footers and different connections despite passing structural checks.
- Keep request-level pending dependency branches inline in the expanded waiting list; do not open a separate dependency popover. Why: 2026-10-05 waiting-list correction.
- Fix activity wrapper width to the authored node width and wrap expanded text; footers must not widen the node. Keep rounded node corners while extending the first footer background behind them to prevent gaps. Why: 2026-10-06 footer expansion and corner corrections.
- When modelling message redelivery after an acknowledgement, explicitly show missing/failed settlement or recorded acknowledgement loss. Acknowledgement does not prove business-side-effect success. Cancellation is its own neutral recorded outcome, and async exhaustion belongs to message/publisher scope. Why: 2026-10-06 remaining-state review.
- A live recording frontier is not a whole-run result: require an ended recording as well as an end playhead before showing final scope/checks. Label gauges as current, counters as cumulative, rates/utilization as time averages, and latency summaries by their observation cohort. Why: 2026-10-05 inspection data audit.
- Timeline legends must fit full timestamps on one baseline and remain CSS-bounded while ResizeObserver catches up after viewport changes. Hover overlays must not cover touch gesture space; preserve full-size touch targets in a separate scrollable row. Browser viewport assertions should wait for measured layouts to settle while still rejecting persistent overflow. Why: 2026-10-05 timeline corrections exposed touch pinch interception and transient legend overflow.
