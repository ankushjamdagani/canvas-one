- When the user authorizes replacing a flow, plan from confirmed problems and behaviors. Treat old UI/protocol as evidence, not constraints; distinguish user decisions, design candidates and unverified technical assumptions. Why: 2026-10-14 AI collaboration planning correction.

- For external plan reviews, send the requested plan first and match additional repository context to user authorization. Treat independent reviewer diagnoses as claims to verify against source, not established bugs. Why: 2026-10-14 Claude PM review payload rejection and overstatement of silent acceptance errors.

- For AI relay cancellation, verify that queued browser work is revoked as well as the caller's wait. Aborting an MCP fetch alone can leave a diagram request deliverable. Why: 2026-10-13 AI collaboration source audit.

- For composite workspace packages, test recovery with dist missing and tsbuildinfo retained. `tsc -p` and unforced incremental builds can report success without restoring declarations; package build scripts use `tsc -b --force`. Why: 2026-10-12 agent-bridge build failure after local setup.

- Verify a real HTTP page after Next dev reports ready. This workspace's scoped PostCSS plugin currently requires webpack for local development; readiness alone masked a Turbopack HTTP 500. Why: 2026-10-12 local AI setup.

Rules learned from past failures, corrections and wasted effort. Loaded every session on every platform. Follow them; cite the rule when it changes your approach.

## Environment and tools

- **Treat headless `agy` exit 0 with empty output or tool-denial output as a failure, including in accept-edits mode.** Sandbox elevation does not grant the CLI's own read/command permissions; use an authorized native executor when its preflight denies them. Why: 2026-09-23 EXEC-PREFLIGHT; 2026-10-06 simulation footer.
- **Don't retry `agy` in a restricted sandbox.** It needs localhost binding and writes under `~/.gemini/antigravity-cli/`; request elevated permissions once or record the task as blocked. Why: 2026-09-10, three failed retries.
- **Typecheck with `npx tsc -b`; never pass `--noEmit false`.** The solution-style root makes `tsc --noEmit -p .` skip `src/`; overriding `noEmit` writes a `.js` beside every source file. For unused-symbol sweeps use a throwaway tsconfig extending the root with `noUnusedLocals`. Why: 2026-10-02 quality sweep and checkpoint removal.
- Verify compiler-library capabilities before using a TypeScript AST API in tooling: the installed native TypeScript 7 compiler exposes its CLI without the previous JavaScript parser API. Keep dependency checks independent of that API or use an explicitly supported parser. Why: 2026-10-11 package boundary guard initially failed on missing `ScriptTarget`.
- **Don't rely on `timeout` or `agy --print-timeout` on macOS.** Use `perl -e 'alarm N; exec @ARGV' <cmd>`. Why: 2026-09-23, 25s timeout ran 79s.
- **`.claude/skills` and `.codex/skills` are symlinks into `.agents/skills`.** Check with `ls -l`; `diff -rq` follows the links and misleads. Why: 2026-09-16 wrong duplication finding.
- **Production e2e needs localhost binding, and Codex's sandbox can't run Chromium.** Ask for elevation up front or keep browser checks with the lead; if denied, report the browser check as blocked. Why: 2026-09-10, 2026-09-12, 2026-09-27 RV-12f/RV-12g.
- **Report unit timeouts as failed checks until verified.** Check contention and rerun focused files, but inspect changed I/O before labeling the result a flake or raising timeouts. Use bounded bulk reads when cursor-by-cursor work regresses stress tests; retain atomic scope and record both results. Why: 2026-09-24/26/27 resource contention; 2026-10-12 scoped IndexedDB cursors caused the existing 101-edit stress test to exceed five seconds, fixed by bulk row/key reads.

Keep the last route for exit renders. Why: 2026-10-07 Codex review (project exit never ran).

Why: 2026-09-30 realism phase 3 (phase 1 probed defaults the app never loads; G1 and B1–B8 surfaced only through the planners).
